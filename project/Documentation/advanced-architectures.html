Integration Failure Handling

Resilience Patterns:
  • Retry with exponential backoff (3-5 attempts, max 30 mins)
  • Circuit breaker: Auto-disable failing integration after 5 consecutive failures
  • Fallback: Use cached/stale data if integration unavailable
  • Alerting: Notify ops if integration down > 30 mins
  • Queue: Store events in DLQ for manual review and retry
